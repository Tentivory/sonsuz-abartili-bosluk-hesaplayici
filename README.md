# Sonsuz Abartılı Boşluk Hesaplayıcı

## Giriş (Ciddiyetle)

Bu proje, insanlık tarihinin en büyük bilimsel atılımıdır. Boşluğun özünü, hiçliğin derinliklerini, ve senin o anki ruh halindeki mutlak anlamsızlığı hesaplayan kuantum-tabanlı (aslında değil) bir algoritmadır. 

Hiçbir şey yapmaz. Ama çok ciddi yapmaz.

## Kullanım

```bash
python bosluk_hesapla.py
```

Program çalıştığında, evrenin en derin boşluklarını ölçer ve sana hayatta ne kadar boş olduğunu yüzde olarak söyler. Sonuç her zaman %100 olacaktır. Çünkü bilim böyle çalışır.

## Özellikler

- Tamamen çalışır (hiçbir işe yaramaz ama çalışır)
- Abartılı ciddi loglar
- Kuantum belirsizlik (random.randint)
- Türkçe felsefi çıktılar

## Uyarı

Bu yazılımı çalıştırmak, evrenin anlamını kaybetmene neden olabilir. Sorumluluk kabul etmiyoruz.
